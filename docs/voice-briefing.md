# 拨号前语音交代

外呼是默认页，底部保留外呼、记录、接听、设置。界面采用用户选定的白色拨号盘、左上 SIM 和绿色听筒。

- 轻点绿色键：使用已配置的豆包实时语音凭据，开启和机主的前台语音交代；此时尚未拨号。
- 单独说“我说完了，你去打”：只接受本轮完整的机主识别定稿，关闭交代的麦克风、播放与 WebSocket 后，调用既有普通外呼流程。交代原文进入该通的任务快照；模型建议不能冒充机主交代。
- 长按绿色键：打开一个文字交代框，核对任务与 SIM 后拨出，保留原有锁屏外呼选择。旧草稿的目标、必问、背景和边界仍能完整编辑及恢复。
- 来电、号码或 SIM 改变、切后台、权限或连接失效、取消都会终止准备。不会自动重试或重拨。

交代使用现有 [Seeduplex 实时语音接口](https://docs.volcengine.com/docs/doubao-voice/access-must-read?lang=zh)，没有额外串联独立 ASR 和 TTS。每次交代最多 180 秒，录音输入和播放缓存有界；仅在主动开始时建立会话，按已有服务账户计费。交代音频不另存录音文件。

实现入口：`ui/CallTaskScreen.kt`、`ui/CallVoiceBriefingHost.kt` 和 `calls/briefing/`。原有运营商电话接听、通话静音归属和电话音频实现不因这次交代界面而替换。

## 验收边界

离线测试使用可控的服务端事件与音频替身验证授权、取消和关闭顺序；模拟器使用真实 Compose 组件验证手势和草稿。以上不能证明真实手机麦克风、回声消除、豆包往返音频和运营商外呼均已成功。当前未连接安卓真机，尚未进行新增语音交代的端到端实机验证。
