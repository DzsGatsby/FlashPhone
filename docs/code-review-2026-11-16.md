## 验证口径

新增确定性回归覆盖以上异常顺序；对可直接替换的旧实现先复现失败，再验证修复。新增结果重试器另外注入临时/持续落盘失败、取消、ACK 和显式恢复。保留正常授权、空识别、多轮对话、打断、真实电话归属、DTMF、录音和总结的既有回归。发布验收另检查正式 APK、同签名覆盖升级、设置与记录保留、公开下载字节一致、应用内更新解析以及 CI。

本轮没有发起真实运营商电话。故障注入的持久化/取消/协议测试不冒充真实客服电话端到端验收；磁盘持续不可写或进程终止仍是明确边界，不能承诺所有失败情形都恢复成功。
