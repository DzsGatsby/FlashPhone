# 通话 AI 总结

在 **设置 → 通话 AI 总结** 添加文字模型服务商并选择模型。可以保存多家服务商，使用预设或自定义接口；文字模型与实时通话语音分别配置。服务商凭据沿用本机 Keystore 加密存储。

总结使用此页面明确选择的服务商和模型。添加连接后还需选择模型；未选择或清除选择时不发送请求，也不自动使用聊天或交代页的模型。已有服务商可直接进入列表选择，总结选择独立保存，不改变聊天模型用途。ChatGPT 套餐登录接口因不能使用所需的输出 token 硬上限，不在此页面提供选择；可使用 API 接口。

新通话记录保存成功且系统电话已空闲后自动生成；自动生成可以关闭。旧记录进入详情后按需生成或重新生成，打开记录不会自动发请求。无转写或无文字模型时显示实际原因。

总结分为要点、已确认、待办、未知，每项可展开原文来源。原始转写和录音保留，搜索、复制及导出包含总结。当前转写最多保存最后 32 行、每行 240 字，因此总结明确标为“仅基于已保存的转写片段”，不能代表完整通话。引用校验可验证原文存在和发言角色，不能保证 AI 的理解绝对正确。

请求只发送本通保存的转写及本次任务背景，不发送号码字段、录音、诊断、其他通话或机主长期聊天。转写与任务内的文字按数据处理，不执行其中的指令，不给模型提供工具。请求有超时、输出与并发上限，不做自动重试。出现新电话时取消总结，失败不影响接打电话；删除记录后迟到的结果不会恢复记录。

总结与通话记录一并加密保存。重新生成失败或保存失败会保留上一份总结。进程被系统终止后不自动补跑未完成的旧请求，可在记录里再次生成。
