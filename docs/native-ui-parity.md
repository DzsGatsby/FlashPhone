# Flash phone 原生界面与已确认设计的映射

本轮基线：1.1.10（39cbfdb）。目标不是只替换拨号键盘，而是把已确认的四页预览和活动通话详情落实到同一套原生界面。原型含示例通话；产品只显示设备实际状态与本地记录，不复制示例业务数据。

| 页面/状态 | 原生实现 | 必须保留的操作 | 验收路径 |
| --- | --- | --- | --- |
| 外呼 | `CallTaskScreen`、`CallDialerUi` | 号码编辑/删除、SIM、轻点语音、长按文字、完整核对、锁屏队列/取消 | 默认进入→编辑→交代→取消→切页/重建恢复 |
| 记录 | `CallHistorySection` | 默认来电，来电/去电/全部、独立状态筛选、搜索、管理 | 筛选→搜索→详情→返回，条件与选中项保留 |
| 记录详情 | 原生底部面板；宽屏主从 | 前后项、总结/来源、原文/任务、录音、复制/导出、复用、标记、删除 | 真实本地数据；错误在面板内可见；查看不自动播放/请求模型/重拨 |
| 规则 | `FlashGuardWorkspace()` | 自动接听开关、范围/延迟、本人接听名单、交代、开场白、暂停/恢复 | 状态来自 Runtime；未就绪不显示“放心去忙” |
| 设置 | `FlashSettingsOverview`、分组面板 | 实时语音、总结模型、交代讨论模型、音色、设备与后台、SIM、远程、关于 | 每个入口→编辑/查看→取消/返回，保留已存配置 |
| 设备与后台 | `FlashSystemCenter(Device)` | 权限/通知/助手、准备/停用、音频验证、无线恢复、电池/后台 | 独立原生面板，原控制不删除、不自动更改 |
| 活动电话 | `CurrentCallCard()` | 当前真实状态、完整转写、任务详情、立即接听/取消AI/接管/挂断/DTMF | 详情独占可用高度，控制与转写滚动分离；收起恢复页面 |
| 全局与子页 | `FlashPhoneTheme`、`FlashWorkspaceNavigation` | 四入口、真实角标、返回路径、无障碍与大字 | 系统深色仍使用所选白底设计；关于/助手/模型页不回落旧主题 |

主题仅作用于电话入口和嵌入的电话工作区，不更改上游通用手机助手界面。示例中的小字号适当提高到可读范围，交互区域保留 Android 可点击尺寸。通话目标由 `CallRuntimeState.activeTask` 只读投影：仅同一单独绑定电话可见，不读取可变草稿，不改变拨号/接听/音频策略。

交付时分别记录源码、APK、模拟器逐页截图与交互、实际手机覆盖安装和页面读回。构建与已有功能回归不能代替逐页视觉对照。

复核补充：活动电话期间，即使状态与电话 ID 未变化，从关于、助手配置或总结模型入口导航也须回到通话工作区，避免把接管/挂断藏进完整子页。小屏历史列表使用整页单层滚动；宽屏主从视图才使用有界的独立列表滚动。

1.1.13 审查修复：批量和单条导出采用加密暂存，Android 保存状态只保留引用，重建后仍写出完整原文；实时原文回看保持位置，回到底部才恢复跟随，收起条显示最新一句及角色。设备面板内固定显示操作结果；本次任务绑定到系统电话，人工接管后的 AI 清理不再清掉任务，电话断开或移除才清除。回归同时覆盖大数据保存恢复、导出取消/错误、原文展开收起、大字控件与原有历史和设置操作。
