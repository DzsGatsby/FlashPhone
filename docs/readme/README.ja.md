## できること

- **着信を代わりに受ける。** AI が応答できる着信を設定し、重要な番号は自分で受けられます。自動応答は一時停止でき、通話を切らずに途中から引き継げます。
- **目的を伝えて電話をかける。** 電話番号と SIM、聞きたいこと、背景、約束してよい範囲を入力し、内容を確認してから発信します。
- **画面ロック中に電話を扱う。** 通話音声ヘルパーとバックグラウンド待機が有効なら、条件に合う着信に応答できます。確認済みの発信タスクは、45 秒以内にロックすると一度だけ発信を試みます。
- **通話を振り返る。** 文字起こしと元のタスクを見比べ、端末内の2チャンネル録音を再生し、対応済みにしたり、別のタスクの下書きに再利用したりできます。

## インストールと初期設定

1. Android 12 以降の端末と有効な SIM を用意します。[GitHub の最新リリース](https://github.com/DzsGatsby/FlashPhone/releases/latest)で `FlashPhone-vX.Y.Z.apk` を入手し、Android の案内に従ってインストールします。求められたら、APK を開いたアプリからのインストールを許可します。
2. 端末で通話音声ヘルパーをワイヤレスペアリングし、Volcengine のリアルタイム音声サービスの認証情報を設定します。音声対応は端末と Android のビルドによって異なります。
3. お互いの音声が聞こえ、手動で通話を引き継げることを確認してから自動応答を有効にしてください。音声確認後に有効にするとバックグラウンド待機も自動で始まり、自動応答を無効にすると待機も解除されます。[設定と互換性のガイド（英語）](../README.en.md)も参照できます。

インストール済みの場合は **設定 → アプリ情報 → アップデートを確認** を使うか、署名済み APK を上書きインストールすると設定と履歴を引き継げます。[更新と移行のガイド（簡体字中国語）](../app-updates.md)を参照してください。

## サービスとデータ

既存の SIM と標準の電話アプリを引き続き利用できます。AI が応答する間、音声は設定した音声サービスに送信され、端末内にも2チャンネルで自動録音されます。左は相手の音声の取り込み、右は端末の電話音声トラックが受け付けた AI 音声です。手動で引き継ぐと録音を停止します。録音と文字起こしは暗号化して端末内に保存され、録音の再生でアップロードは行いません。割り込みで再生待ち音声が破棄される場合があり、右チャンネルは相手が実際に聞いた証明にはなりません。通信事業者と音声サービスの利用料が別途かかることがあります。

録音は1件600秒、50件、合計200 MiBまでで、必要に応じて古いものから削除されます。ペアリングと端末が許可する権限の設定後、接続済みの信頼できる Wi-Fi でワイヤレスデバッグの復旧を試み、起動・ロック解除・更新後には以前許可した着信待機の復旧を試みます。システムの信頼確認、強制停止、メーカーの制限を回避せず、root 権限も取得しません。新しい録音と復旧処理はオフラインで確認済みですが、実際の電話録音と再起動・更新後の復旧は端末での検証が必要です。
