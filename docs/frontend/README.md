# Flash phone 通话工作区

基于用户提供的 `flash phone index.html` 继续设计。`index.html` 是可直接打开的完整离线前端，不需要安装依赖、字体服务或 CDN。

## 实际可用范围

- 桌面常驻侧栏、工作台、记录数据库、原地详情；手机底部导航与完整导航菜单。
- 搜索页面、号码、摘要和原文；筛选、排序、上一条/下一条、处理标记、浏览器返回和详情深链接。
- 独立外呼任务：号码、SIM、目标、问题、背景、边界；草稿自动保存，核对和复用不会直接实拨。
- 接听范围、名单、开场白、音色偏好、时长与分类交代的本地编辑。
- 复制原文、导出 JSON、选择真实本地音频回放；音频不上传、不持久化，不假造录音。
- 浅色/深色/跟随系统；搜索快捷键、弹窗焦点管理、减弱动画与响应式布局。

## 边界

这是**前端交互预览**。数据、设备和通话均为明确标记的示例；不会发起真实电话、创建模型会话、授予系统权限或保存 API Key。页面中的控制台链接打开已有真实服务；预览不替换 `tools/control-plane/dashboard.html` 或 Android 原生界面。

Android 1.1.3 已将此设计的工作区层级与视觉落实到 Compose 原生界面，连接真实待命、记录、录音、接听设置和本机加密任务草稿。原生入口为 `CallSettingsScreen.kt`；本目录继续作为独立设计预览维护，示例数据不进入 APK。

编辑数据保存在当前浏览器的 `flashphone.workspace.preview.v3` 项。它不是加密保险箱，不用于保管凭据。录音需要用户选择真实音频文件，保留在当前页面生命周期。示例转写与该文件不自动对齐。

## 构建

```sh
python3 docs/frontend/build.py
python3 -m http.server 8931 --bind 127.0.0.1 --directory docs/frontend
```

`shell.html` 定义文档骨架；`base.css` / `core.js` 保留附件中的基础组件、示例资料、编辑和模拟流程；`workspace.css` / `workspace.js` 定义新的设计系统、信息结构和可用交互。`index.html` 为构建产物。源码与产物一起保存，便于直接分享 HTML。

## 设计取舍

目标是接近 Notion 的清晰度与操作连贯性：内容先行、安静的表面、明确的对象层级、原地展开。并非复制其品牌或把电话产品改成笔记软件。

- 以工作台、通话记录、外呼任务组织日常工作；接听规则、交代、设备和设置承接配置复杂度。
- 单一暖灰底色、细分隔线、适量语义状态色；统一线性 SVG 图标，系统中文字体，无外部字体下载。
- 去除手机壳、重渐变、模糊与循环装饰动画；工作区不持续重绘。
- 保留附件能力而非保留固定页数。外呼改为完整任务编辑页和独立核对页，不强制四步向导。
- ui-ux-pro-max 检索建议中的低阴影、清晰层级、单色与功能强调色适用；营销落地页结构和衬线字体不适合此中文任务工具，因此未采用。

## 验收重点

实际操作：进入 → 搜索/筛选 → 详情 → 切换记录 → 返回保留条件；填写任务 → 关闭 → 刷新恢复 → 核对 → 模拟通话 → 记录对照；编辑交代 → 切页/刷新；主题与键盘导航。检查 375px 手机、平板、桌面和横屏；不以静态截图替代这些流程。
