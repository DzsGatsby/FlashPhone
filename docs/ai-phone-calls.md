# AI 接打电话（实验功能）

在「设置 → AI 接打电话」中配置火山端到端实时语音，通过现有 SIM 进行运营商电话沟通。保留原默认拨号器，支持指定 SIM 拨号、AI 接听、挂断和人工接管。VoIP 应用电话不属于此功能。

## 准备与首次验证

1. 连接 Mika 内置助手，允许电话和通知权限。此实现的通话伴侣模式要求 Android 12+、主用户和可用 SIM；音频路径还取决于机型及 ROM。
2. 在火山豆包语音控制台开通「端到端实时语音」，把有该资源权限的 API Key 填入本机设置。只有语音识别权限的 Key 不够；也支持旧版 App ID + Access Key。凭据使用 Android Keystore 加密保存。
3. 在「设置」填写开场白、通话目的、最长时长和声音；点击「启用 AI 电话」。准备成功只说明系统权限与音频接口满足预检，不代表对端实际听得见。
4. 先拨打一个已授权的测试号码，或手动 AI 接听测试来电。确认 AI 能听懂对方、对方能听到 AI、说话打断有效，再测试人工接管和挂断后的正常电话。
5. 只有确认双方声音正常后，才能勾选本机实测确认并开启自动接听。默认不开启自动接听，名单外和隐藏号码默认不接；接听所有来电是单独选项。音频模式或 ROM 构建改变会使确认失效。

系统路由可初始化、PCM 字节流动和真实电话双向可听是不同层级的证据。不要用预检或本地协议测试替代实机通话验收。

## 通话与费用

同一时刻只处理一通普通运营商电话。不拨紧急号码、短号、USSD/MMI 控制代码，不介入会议、视频、外部或其他应用管理的电话。可在设置中持久指定默认拨号卡；本次明确指定优先于默认设置。默认卡失效时提示重新选择，不悄悄换另一张卡。

每次 AI 通话默认最多 120 秒，可设为 15–600 秒。达到上限后尝试结束该通电话，并读回 Android 结果；故障时停止 AI 音频并交还系统拨号器。人工接管只停止 AI，不挂断。

运营商通话费与火山语音费用独立计算。火山服务可能按 Token 后付费；没有后台空闲语音会话、自动重拨或无限重连。开启自动接听后，符合规则的真实来电会产生对应服务用量。

## 代接规则与日常使用

接听页优先显示就绪状态、自动接听和当前通话。自动接听可限定名单或全部来电；“本人接听”名单优先，保留系统正常响铃。可暂停 30 分钟或 2 小时，到期只处理之后的新来电；来电倒计时可取消。已有通话不会因暂停而挂断。

通话中可看已定稿文字并人工接管，结束后可按号码/原文搜索最近 50 通、标记已处理、删除或清空。没有收到的原文不自动补写成事实。

## 交代、Codex 与音色

在“接听交代”中保存场景、回复方式和有效期，支持长期、今天或两小时。新通话只读取启用且未过期的交代；通话期间编辑在下一通生效。保存规则加密落盘。

“与 Codex 商量”使用随包提供的 OpenAI Codex App Server 0.167.0 ARM64 官方引擎，配置官方 OpenAI API Key 与可用模型后，可继续原会话、停止回复或新建会话。有效的已保存交代会传入每次新建/恢复的 Codex 会话。讨论稿只有点“保存为交代”并检查内容后才影响电话。上游自动提炼记忆在此版本未启用，不把已保存规则或聊天记录等同于自动记忆。OpenAI 会接收讨论内容和已保存的有效交代；引擎会话位于应用私有、不参与备份的目录，不自动发给来电者。

音色页提供照稿录音、回听、重录、上传训练、查询进度、官方试听与应用音色。需要火山同一项目的正式 S_ 音色槽位及复刻权限；先查现有额度和费用，上传前由机主确认。App 不自动购买槽位；训练成功和真实电话音色通过分别验收。录音在应用私有目录暂存，可删除或重录。

完整需求来源与各项实测状态见 [产品说明](ai-phone-calls-product.md)。

## 本地记录和数据

AI 开场说明身份。火山接收通话语音以生成回答；本地不保存原始 PCM，通话文字记录有条数和长度上限并加密存储。来电内容不能授权 AI 执行支付、账号、消息或其他外部操作。

设置开关、凭据和自动接听规则只在手机配置。停用会撤销本功能建立的通话伴侣注册，并还原它改动的 app-op。原本已存在的外部配置不会被清除。

## 电脑连接与模型工具

授权的 LAN/USB MCP 提供：

- `mika_call_state`：就绪信息、SIM、当前通话和 `call_id`。
- `mika_call_dial`：传 `number`，多卡时传 `sim_id`。
- `mika_call_answer` / `mika_call_hangup`：先查状态，必须传该通电话的 `call_id`；通话变更会拒绝。
- `mika_call_takeover`：停止当前 AI 音频，保留运营商通话。

这些接口沿用电脑连接鉴权，云转发还受现有设备访问开关限制。模型侧对应 `phone_call_*` 工具；手机本地任务经过既有审批机制。远程 `mika_run_task` 不会绕过其确认限制，需要直接使用专用电话 MCP 工具。收到不确定拨号结果时先查状态，不得直接重拨。

## 开发验证

- `:app:testDebugUnitTest` 覆盖火山握手、音频帧、插话、关闭、超时、背压及号码/SIM/自动接听策略。
- `:core:test` 覆盖 MCP 身份和设备访问边界、参数类型与通话 ID、工具风险和提示词快照。
- `:app:assembleDebug -PdevInstall` 可并排安装 Mika Dev，保留原版与数据。生产 APK 必须沿用原签名才能原位升级。
- 经已授权 ADB，可运行只读 `CallAudioPreflight` 查看 shell UID、权限、API 与运营商音频设备。它不拨号、不开音频流，也不会标记真实双向验证通过。

接口依据：[火山实时语音 3.0](https://docs.volcengine.com/docs/doubao-voice/end-to-end-real-time-voice-full-duplex-version?lang=zh)、[AOSP AudioManager](https://android.googlesource.com/platform/frameworks/base/+/android-16.0.0_r1/media/java/android/media/AudioManager.java)。

Codex 原生运行时由 `tools/codex/prepare-runtime.py` 按固定官方版本和 SHA-256 下载/校验后打包，二进制不提交 Git。离线构建可传 `-PphoneCodexArchive=/absolute/path/to/verified.tar.gz`；`-PphoneCodex=false` 生成不带引擎的轻量 APK，UI 会显示引擎不可用。首次下载约数十 MB，完整 APK 因内置引擎明显增大。Android 为实验移植，须验证 App UID 启动、真实 API 会话与恢复，不能仅凭 shell 握手成功宣布可用。
