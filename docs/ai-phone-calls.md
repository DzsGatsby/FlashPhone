# Flash phone：AI 接打电话

打开 Flash phone，进入接听、电话任务、记录、设置四个工作页；先在本模块设置页配置火山端到端实时语音，通过现有 SIM 进行运营商电话沟通。保留原默认拨号器，支持指定 SIM 拨号、AI 接听、挂断和人工接管。VoIP 应用电话不属于此功能。

## 准备与首次验证

1. 连接 Flash phone 通话音频助手，允许电话和通知权限。此实现的通话伴侣模式要求 Android 12+、主用户和可用 SIM；音频路径还取决于机型及 ROM。
2. 在火山豆包语音控制台开通「端到端实时语音」，把有该资源权限的 API Key 填入本机设置。只有语音识别权限的 Key 不够；也支持旧版 App ID + Access Key。凭据使用 Android Keystore 加密保存。
3. 在「设置」填写开场白、通话目的、最长时长和声音；点击「启用 AI 电话」。准备成功只说明系统权限与音频接口满足预检，不代表对端实际听得见。
4. 先拨打一个已授权的测试号码，或手动 AI 接听测试来电。确认 AI 能听懂对方、对方能听到 AI、说话打断有效，再测试人工接管和挂断后的正常电话。
5. 只有确认双方声音正常后，才能勾选本机实测确认并开启自动接听。默认不开启自动接听，名单外和隐藏号码默认不接；接听所有来电是单独选项。音频模式或 ROM 构建改变会使确认失效。

系统路由可初始化、PCM 字节流动和真实电话双向可听是不同层级的证据。不要用预检或本地协议测试替代实机通话验收。

## 通话与费用

同一时刻只处理一通普通运营商电话。不拨紧急号码、短号、USSD/MMI 控制代码，不介入会议、视频、外部或其他应用管理的电话。可在设置中持久指定默认拨号卡；本次明确指定优先于默认设置。默认卡失效时提示重新选择，不悄悄换另一张卡。

事情说清后，AI 可主动自然收尾，不要求对方先说再见。最后一句播完会留出短暂的插话时间，对方继续说话时保留通话。每次 AI 通话默认最多 120 秒，可设为 15–600 秒。达到上限后尝试结束该通电话，并读回 Android 结果；故障时停止 AI 音频并交还系统拨号器。人工接管只停止 AI，不挂断。

运营商通话费与火山语音费用独立计算。火山服务可能按 Token 后付费；没有后台空闲语音会话、自动重拨或无限重连。开启自动接听后，符合规则的真实来电会产生对应服务用量。

## 主动拨出一项电话任务

进入“电话任务”，填写打给谁、这次希望办成什么、必须问清的问题，再按需展开背景和不能承诺的事项。默认拨号卡直接显示，可以只为本次换卡。先预览号码、SIM 和完整任务，再确认拨出；设备未准备好也可先写和预览草稿。切页、进入子页返回和 Activity 重建保留草稿。

本次任务以独立快照传给实时语音，先核对通话对象，再围绕目标提问或办理明确授权的普通电话事项。询问不会自动升级预约；缺少关键条件或超出边界时交还机主。任务不覆盖长期交代、全局设置或其他通话。拨出、接通和结束都不等于目标达成。

结束后从“记录”按目标或号码查找，展开本次任务和问答原文逐项核对。可将旧交代复制到新草稿；已有草稿先确认替换，复用不会自动拨号。

## 代接规则与日常使用

接听页优先显示就绪状态、自动接听和当前通话。自动接听可限定名单或全部来电；“本人接听”名单优先，保留系统正常响铃。可暂停 30 分钟或 2 小时，到期只处理之后的新来电；来电倒计时可取消。已有通话不会因暂停而挂断。

通话中可看已定稿文字并人工接管，结束后可按号码/原文搜索最近 50 通、标记已处理、删除或清空。没有收到的原文不自动补写成事实。

## 交代、Codex 与音色

在“接听交代”中保存场景、回复方式和有效期，支持长期、今天或两小时。新通话只读取启用且未过期的交代；通话期间编辑在下一通生效。保存规则加密落盘。

“与 Codex 商量”使用随包提供的 OpenAI Codex App Server 0.167.0 ARM64 官方引擎，配置官方 OpenAI API Key 与可用模型后，可继续原会话、停止回复或新建会话。有效的已保存交代会传入每次新建/恢复的 Codex 会话。讨论稿只有点“保存为交代”并检查内容后才影响电话。上游自动提炼记忆在此版本未启用，不把已保存规则或聊天记录等同于自动记忆。OpenAI 会接收讨论内容和已保存的有效交代；引擎会话位于应用私有、不参与备份的目录，不自动发给来电者。

音色页提供照稿录音、回听、重录、上传训练、查询进度、官方试听与应用音色。需要火山同一项目的正式 S_ 音色槽位及复刻权限；先查现有额度和费用，上传前由机主确认。App 不自动购买槽位；训练成功和真实电话音色通过分别验收。录音在应用私有目录暂存，可删除或重录。

完整需求来源与各项实测状态见 [产品说明](ai-phone-calls-product.md)。

## 本地记录和数据

默认开场白会说明 AI 身份；自定义开场白按填写的内容播报，留空则等待对方先开口。对方问及身份时如实说明。火山接收通话语音以生成回答；来电内容不能授权 AI 执行支付、账号、消息或其他外部操作。

AI 处理通话期间默认自动录音，在「记录」中手动播放，不自动播放或上传录音。16 kHz 双声道 WAV 左声道是采集到的对方声音，右声道是设备电话音轨已接受的 AI 音频；插话时清空播放队列可能丢弃尚未播出的数据，所以右声道不能证明远端实际听到了每一句。接管、故障或退出 AI 后停止录制，不继续录普通人工通话。

录音通过 Android Keystore 密钥分块加密，保存在不参与系统备份的应用私有目录；通话文字仍按原有条数和长度上限加密保存。每份最多 600 秒，最多 50 份、总量 200 MiB，需要空间时先移除最旧录音，文字记录可能仍在。监控流中断时尽量保留可播放的部分录音并标记；无法保存时保留文字，不阻塞电话。录制和解密回放时有私有临时 WAV，使用后清除，崩溃遗留在下次应用初始化时清理。删除对应历史也删除录音。

新录音路径已经过离线协议、时间线、加密、损坏、取消和空间限制测试；真实电话的双声道录音及回放尚待实机验证。

设置开关、凭据和自动接听规则只在手机配置。停用会撤销本功能建立的通话伴侣注册，并还原它改动的 app-op。原本已存在的外部配置不会被清除。

## 锁屏接打与后台待命

- **接听**：通过首次双向音频验证并开启自动接听后，后台待命自动启动，无须另开一个授权按钮；关闭自动接听同时撤销待命。退出界面或锁屏后，状态以系统通知和接听页读回为准；仅对符合现有规则的来电启用 AI。助手尚未恢复时可先保持待命进程继续恢复，但不接入 AI 音频，保留系统接听。通话中可以用通知取消或接管。
- **拨出**：在电话任务里核对号码、SIM 和任务，选“锁屏后拨出”并确认，在 45 秒内锁屏。仅尝试一次；锁屏前可以取消，超时、已有通话或条件失效时不拨。没有自动重拨，重启也不会补拨。
- **权限与恢复**：系统电话权限用于运营商电话；通知用于待命状态、取消和接管；音频助手负责设备侧双向通话音频。默认恢复流程通过已连接且认证的助手尝试授予并读回本应用的安全设置权限、自身电池例外及后台 app-op，不申请 root。明确关闭恢复后不重新授予，并按归属恢复本功能改过的配置。普通锁屏与开机后从未解锁不同，强行停止、无可用网络或厂商限制仍可能中断恢复。待命时不会上传音频。
- **真机验收**：从正常进程启动，禁止在真实通话窗口运行 instrumentation 或重新安装。分别测刚锁屏、锁屏静置较久后的自动接听，以及已确认的锁屏拨出任务、过 45 秒不锁屏、取消后锁屏、占线、权限/助手失效、超过 60 秒双向对话、打断和人工接管。系统能拨通与对端能听到均需单独确认。锁屏静置时若连接不可用，从电话设置查看本机后台/电池选项；设备实现可能有差异。

Flash phone 的通话助手负责运营商电话的双向音频；Android 的普通电话权限不包含这项能力。首次可从手机的通话助手页面按系统提示进行无线配对，不用接电脑。在系统配对窗口保留 6 位码，从 Flash phone 的通知中输入。无线调试用于启动和恢复音频助手；助手在运行时，电话不经过调试连接。保存了安全设置授权且已经配对后，即使助手暂未运行，也会在已连接的受信任 Wi-Fi 上尝试重新开启无线调试、连接并恢复助手。系统 Wi-Fi 信任提示仍由机主确认，不绕过信任或设备限制；网络恢复后可重试，失败有上限，不无限重连。

应用更新从「设置 → 关于 → 检查更新」下载，按 Android 提示覆盖安装。开机完成、首次解锁和应用更新事件会尝试恢复后台接听；条件是已经解锁过，AI 电话启用、自动接听和本机双向音频确认仍有效，不需要额外的待命授权。助手连接恢复后才具备通话音频条件，原本关闭、暂停和名单规则保持有效。首次仍须完成配置和双向验证，再开启自动接听；不会恢复已过期的拨出任务，也不会自行拨号。事件恢复和免电脑重新拉起助手目前只核验代码及离线策略，重启/升级后的手机实际恢复仍待验；不能承诺厂商系统下永久保活。

## 开发验证

- `:app:testDebugUnitTest` 覆盖火山握手、音频帧、插话、关闭、超时、背压及号码/SIM/自动接听策略。
- `:core:test` 覆盖 MCP 身份和设备访问边界、参数类型与通话 ID、工具风险和提示词快照。
- `:app:assembleDebug -PdevInstall` 可并排安装 Flash phone，保留原 Mika 与数据。生产 APK 必须沿用原签名才能原位升级。
- 经已授权 ADB，可运行只读 `CallAudioPreflight` 查看 shell UID、权限、API 与运营商音频设备。它不拨号、不开音频流，也不会标记真实双向验证通过。

接口依据：[火山实时语音 3.0](https://docs.volcengine.com/docs/doubao-voice/end-to-end-real-time-voice-full-duplex-version?lang=zh)、[AOSP AudioManager](https://android.googlesource.com/platform/frameworks/base/+/android-16.0.0_r1/media/java/android/media/AudioManager.java)。

Codex 原生运行时由 `tools/codex/prepare-runtime.py` 按固定官方版本和 SHA-256 下载/校验后打包，二进制不提交 Git。离线构建可传 `-PphoneCodexArchive=/absolute/path/to/verified.tar.gz`；`-PphoneCodex=false` 生成不带引擎的轻量 APK，UI 会显示引擎不可用。首次下载约数十 MB，完整 APK 因内置引擎明显增大。Android 为实验移植，须验证 App UID 启动、真实 API 会话与恢复，不能仅凭 shell 握手成功宣布可用。
